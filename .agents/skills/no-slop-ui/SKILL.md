# No Slop UI

Build UI for real human productivity. The goal is functional, honest, and clean. Not impressive, not dramatic: **crisp and normal**.

## The Standard (Things 3 / Linear / Raycast feel)

- **Cards / Containers:** 8–12px radius max, subtle 1px border (`border-neutral-200 dark:border-neutral-800`), minimal shadow. No floating shells, no glowing borders.
- **Buttons / Actions:** Solid or simple subtle borders, 6–8px radius. No gradient washes, no unnecessary pills everywhere.
- **Typography:** Clear hierarchy, 14–15px body, crisp font, normal casing.
- **Spacing:** Predictable scale (4/8/12/16/24px).
- **Transitions:** 100–150ms ease. Opacity and color only. No bouncy springs or hover transforms.
- **Inputs:** Solid border, simple focus ring, quiet placeholder.
- **Icons:** 16–18px, monochrome or subtle context color.

## Hard Banned Patterns

- No floating glassmorphism panels or blurred backdrops without functional need.
- No gradient backgrounds as decoration.
- No oversized rounded corners (20px+ on simple buttons or rows).
- No unnecessary cards nested within cards.
- No fake charts, decorative statistics, or metrics grids.
- No decorative status dots or excessive colorful badges.
